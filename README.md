## 七、关于优惠码的几个常见问题

**优惠码能和套餐折扣叠加吗？** 不能。搬瓦工的优惠码是针对订单总价的循环折扣，套餐本身的价格就是最终原价，码在此基础上打折，不存在"套餐打折 + 码再打折"的叠加。

**续费时优惠码还有效吗？** 有效。搬瓦工的优惠码是循环折扣，首次购买时用了几折，续费、升级都按这个折扣算，不会恢复原价。这也是为什么挑码时折扣力度比单次省多少更重要的原因。
